# Task 01: Data Cleaning and Preprocessing

## Project Overview

This project demonstrates data cleaning and preprocessing techniques using Python and Pandas on a sample employee dataset.

## Objectives

* Identify missing values and duplicate records.
* Handle missing values using median imputation.
* Remove duplicate records.
* Standardize inconsistent text formatting.
* Export the cleaned dataset to a CSV file.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Google Colab

## Files

* `Data_Cleaning_Preprocessing.ipynb` — Notebook containing the code, outputs, and explanations.
* `Cleaned_Dataset.csv` — Cleaned sample employee dataset.

## Conclusion

The dataset was cleaned and verified to ensure that no missing values or duplicate rows remained.
