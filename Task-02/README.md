# Task 02: Exploratory Data Analysis (EDA)

## Project Overview

This project explores the Advertising dataset using Python to identify patterns, distributions, correlations, and potential outliers.

## Objectives

* Inspect the dataset and calculate descriptive statistics.
* Analyze distributions using histograms.
* Explore relationships using scatter plots.
* Examine correlations using a heatmap.
* Identify potential outliers using boxplots.
* Summarize key findings.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset

The Advertising dataset contains TV, Radio, and Newspaper advertising expenditure, along with Sales.

## Files

* `Exploratory_Data_Analysis.ipynb` — Notebook containing the code, visualizations, outputs, and explanations.

## Conclusion

The analysis identifies TV advertising as the channel most strongly correlated with Sales in this dataset. Correlation indicates association, not necessarily causation.
