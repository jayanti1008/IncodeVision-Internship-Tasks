# Task 04: Customer Segmentation Analysis

## Project Overview

This project uses K-Means clustering to segment mall customers based on their annual income and spending scores.

## Objectives

* Explore and understand customer data.
* Select relevant features for clustering.
* Standardize the selected features.
* Determine a suitable number of clusters using the Elbow Method.
* Apply K-Means clustering.
* Visualize and interpret customer segments.
* Evaluate clustering performance using the Silhouette Score.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Files

* `Customer_Segmentation_Analysis.ipynb` — Notebook containing the analysis, visualizations, clustering, and evaluation.
* `Customer_Segments.csv` — Exported customer segmentation results.

## Conclusion

The project identifies five customer segments based on annual income and spending scores. These segments can help businesses understand different customer groups and develop more targeted marketing strategies.
